# 🌿 Консольный симулятор жизни

Симулятор экосистемы с хищниками, травоядными и растениями.

## Структура
- **organism.py**: классы организмов (Plant, Herbivore, Predator)
- **ecosystem.py**: классы Population и Ecosystem
- **utils.py**: вспомогательные функции
- **main.py**: точка входа

## Запуск
bash
python main.py
